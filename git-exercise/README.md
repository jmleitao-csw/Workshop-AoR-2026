# Git exercise files

Use this folder together with `../../exercises/git-workshop.md`.

## Student starter file

- `src/main/java/workshop/git/GreetingService.java`

## Suggested setup for the workshop

1. Start on `main` with the starter file
2. Students create `feature/personalize-message`
3. Students change the message on the feature branch
4. Instructor or students change the same line differently on `main`
5. Students rebase and resolve the conflict in IntelliJ
