# Java engineering workshop repo

This repository contains the runnable exercise assets for the workshop.

## Structure

- `git-exercise/` - starter files for branch, rebase, and conflict practice
- `code-review-exercise/` - intentionally problematic Java code for review practice
- `testing-exercise/` - business-rule regression exercise with starter tests

## Open in IntelliJ

1. Open the folder `workshop-repo`
2. Import it as a Maven project
3. Use the exercise guides in `../exercises/` together with the source files here

## Solutions

Each exercise folder contains a `solutions/` directory with instructor/reference versions.

## Suggested use in the session

1. Start with `git-exercise/`
2. Move to `code-review-exercise/`
3. Finish with `testing-exercise/`
