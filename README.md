# Java Engineering Workshop Repo

This repository contains the runnable exercise assets for the workshop.

## Structure

- `git-exercise/` - starter files for branch, rebase, and conflict resolution practice
- `java-calculator/` - combined code review and unit testing exercise using a simple calculator project

## Open in IntelliJ

1. Clone this repository
2. Open the root folder in IntelliJ IDEA
3. Import it as a Maven project

## Suggested use in the session

1. Start with `git-exercise/` — practise branching, rebasing, and resolving conflicts
2. Finish with `java-calculator/` — review an open PR, identify issues and missing functionality, then validate the instructor's fixes and approve
